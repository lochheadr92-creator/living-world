Figures are settlement totals for individual histories. Grain mixes in stacks. Destinations are measured differences between histories and cannot identify the fate of an individual extra grain.

## Where the labour went

Travel is a call to the movement step, including unsuccessful and interrupted attempts; distance is actual displacement in tiles. Work is a call to the activity work handler. Arrival can use both phases in one tick. The grain categories include all tilling, planting, tending and harvesting; wild grain gathering; deposit, withdrawal and haul tasks explicitly carrying a grain plan; milling and feed mixing. Mixed cargo charges the entire task. General eating, giving, animal husbandry and unlabelled transport remain outside this subtotal. Settlement handler totals also include activities such as sleep.

## Verification

All 144 end-of-day world conservation checks passed. On each day, opening stock plus creation minus consumption and spoilage equalled measured stock for grain, seeds, flour, bread and prepared feed. Opening field grain plus ripening minus collections and field rot equalled standing grain. In all twelve runs the mixing recipe reconciled independently. Archived Aspen rules-261 cross-check: base 12/12 daily hashes, day 12 f07b5016 (archive f07b5016); boost 12/12 daily hashes, day 12 b18292a9 (archive b18292a9).

Working simulation source SHA-256 before instrumentation: `101f840415aa8b5f24ccc24f96d138ac082add98029f3e7277313237aa5c1fcf`. Each JSON contains per-item ledger reasons, transfer routes, opening and closing inventories, labour by activity and daily hashes. The field target and observations run in a disposable source copy. See PROTOCOL.md for the pre-run comparison.

## Reproduction

From the feature checkout in PowerShell:

~~~powershell
$ev = (Resolve-Path review_evidence/grain-surplus-20261120).Path
$probe = Join-Path $env:TEMP ("grain-surplus-" + [guid]::NewGuid())
python "$ev/setup.py" $probe
New-Item -ItemType Junction -Path "$probe/node_modules" -Target (Resolve-Path node_modules) | Out-Null
Push-Location $probe
try {
  foreach ($seed in "aspen","river") {
    foreach ($arm in "base","wild","t18","t24","boost") {
      node node_modules/vite-node/dist/cli.mjs trace.ts $seed 266 $arm "$ev/$seed-266-$arm.json"
    }
  }
  foreach ($arm in "base","boost") {
    node node_modules/vite-node/dist/cli.mjs trace.ts aspen 261 $arm "$ev/aspen-261-$arm.json"
  }
} finally { Pop-Location }
python "$ev/summarize.py"
~~~

## Supplementary meal labour

A second observer follows each pack or store meal from departure and counts its full travel and work when at least one bite actually consumes raw grain. Multiple grain bites count the meal once. Mixed meals charge their entire duration. These activities are separate from the production and transport subtotal. A bite eaten at the wild source already belongs to gathering. Failed generic meal trips without a grain bite cannot be attributed this way.
