# Living World gap ledger

One row per candidate capability gap, G01 to G233, taken from the 7 November 2026 gap map (brain note
`daily/2026-11-07-living-world-gap-map`, appendix; analysed at rules 162). This ledger reconciles every row against
**rules 176** (integrate `main` after `10d3adf2`). It is a working record for the continuous-gap stream: a fresh session resumes at the
first non-terminal row of the queue below. Proposals here are not approvals; the owner's decisions are the brain notes in
`decisions/manual/claude-living-world/` and the open owner lines in `loops.md`.

## How the statuses were set

- Eight read-only reconcilers each took a slice of about 30 rows and read the clean rules-176 tree (`living-world-empty-food` at
  `10d3adf2`) on 2026-11-09. Method: list what exists with `file:line` before claiming absence, and try at least five grep terms.
  The terms are in each evidence cell.
- A mechanical check then tested all 770 `file:line` citations against that tree: 765 resolve; five cite a line one to five past the
  end of their file (G19, G26, G89, G90, G205), flagged in their rows.
- No runtime check was made. `OPEN-VERIFIED` means absence was read from source at rules 176. It is not a measured effect, and
  where a row says "rarely reached" the rate comes from older evidence, not a rerun.
- Lead review (the session that committed this file) changed 16 rows to `GATED` because a fix would have to edit a file another
  session holds with uncommitted edits. It did not re-derive the other 217 verdicts.
- The 42 rows the map had refuter-checked (G01 to G39, G41, G42, G44) were re-read like the rest. All are still open, closed
  or narrowed as the table shows; none was refuted outright.
