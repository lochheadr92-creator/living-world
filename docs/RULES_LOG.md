# Rules log

One dated paragraph for each rules version: what it changed, what was measured and where the evidence is. Newest first. Each
paragraph was true when it was written and is not updated afterwards, so check anything that matters against the code and a live run.

Search this file for "Rules N checkpoint" or "Rules **N**". Do not read it whole. The current rules version is
`CURRENT_RULES_VERSION` in `src/sim/rulesversion.ts`.

To record a new rules version, add its paragraph directly under "Checkpoints (newest first)".

These paragraphs were in `AGENTS.md` and `CLAUDE.md` until 20 November 2026 and were moved here word for word. Older documents
that cite either file for a rules checkpoint mean this file.
